## 1. フロントエンド

| 項目 | 選定内容 | 備考 |
|---|---|---|
| プログラミング言語 | JavaScript (ES6+) | これまでの方針(型付き言語は使用しない)を踏襲し、TypeScriptは導入しない。将来的に型安全性が必要になった場合はTypeScript移行を検討する |

| スタイリング | Tailwind CSS | 指定により採用。ユーティリティクラスをJSX内に直接記述する構成とし、別途CSSファイルの命名規則を考える必要がない |
| テスト | Vitest / React Testing Library | Viteとの親和性が高いVitestを採用する |

## 5. 主要な機能の実装方針

| 機能 | 使用する技術 | 備考 |
|---|---|---|
| ドラッグ&ドロップ | dnd-kit | Reactの仮想DOM上でブラウザ標準のHTML5 Drag and Drop APIを直接扱うと状態管理が煩雑になるため、Reactと親和性が高く現行で活発にメンテナンスされているdnd-kitを採用する |
| データ永続化 | PostgreSQL(バックエンド経由) | ブラウザのlocalStorageではなく、REST API経由でDBに保存する構成に変更した |
| 日付入力 | HTML標準の `<input type="date">` | React内でも標準のまま使用し、専用の日付選択ライブラリは導入しない |

## 7. 技術選定の理由

- バックエンドはJava/SpringBoot(ビルドツールはGradle)、フロントエンドはReact(Next.jsは今回対象外、スタイリングはTailwind CSS)、データベースはPostgreSQLという指定を前提とした
- 上記以外のツール(ORM・マイグレーション・DnDライブラリ等)は、指定されたフレームワーク・言語のエコシステムで標準的・広く使われているものを選定し、学習効果と情報の得やすさを優先した
- 個人開発・学習目的のプロジェクトであり大規模なトラフィックは想定しないため、認証基盤や分散システム向けの技術(メッセージキュー等)は導入しない
- 将来的な拡張(複数ユーザー対応等)に備え、フロントエンド・バックエンド・DBを分離した構成としたが、現時点ではスコープ外の機能(認証等)は実装しない
